# Notices

## auth-capture scheme

The `auth-capture` payment scheme implemented in this repository is based on the `x402-escrow` proposal originated by Agentokratia, published as [`@agentokratia/x402-escrow`](https://www.npmjs.com/package/@agentokratia/x402-escrow) on npm under the MIT License. The proposal was first opened as issue 834 on the x402 protocol repository: <https://github.com/x402-foundation/x402/issues/834>.

At the time of writing, the source repository referenced by the npm package (`github.com/Agentokratia/x402-escrow`) is no longer publicly accessible on GitHub. This notice preserves attribution to the original proposers regardless.
